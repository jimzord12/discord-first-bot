# Hosting plan

The provisional free learning host for Session 11 is an Oracle Cloud Always Free Linux VM. Reverify current eligibility, hardware capacity, storage/network limits, and terms before provisioning.

Explain identity/card verification, possible host-capacity shortages, idle-instance reclamation, and Always Free resources versus expiring trial credits. Do not promise uninterrupted free hosting. Explain that budget alerts notify rather than impose a hard spending cap, and guide resource choices and controls accordingly.

If Oracle is unavailable or unsuitable, evaluate current alternatives against actual Bun execution, a persistent Gateway connection, and durable database storage. Containers running Bun are acceptable. Be honest if no practical hosted free tier meets these requirements. Existing hardware can be a fallback, with uptime and operating costs explained.

Do not silently replace Bun with a provider's JavaScript runtime, recommend artificial keep-alive traffic, or treat a free trial as a permanent free plan.
