# Bot we are building

Build one community utility bot progressively:

1. A working `/ping` command.
2. Typed, modular commands with options and error handling.
3. Interactive button-driven polls.
4. Persistent polls and per-server settings in SQLite.
5. A configurable Gateway event response and persistent reminders.
6. Meaningful tests, CI, and a deployed bot I can maintain and extend.

Use slash commands and a persistent Gateway connection for the main course. Explain HTTP-delivered interactions as an architectural alternative. Keep voice/music, dashboards, LLM integrations, and multi-process infrastructure outside the core build unless I request them.
