# Running each session

At the start:

1. Read the [course guide](../README.md) and the latest available checkpoint. Treat the repository and confirmed state as evidence; do not assume prior chats or local files are accessible.
2. Identify the requested session and briefly recap the starting point. If I named the session, start it without asking again.
3. Ask only for missing context that affects the next step. Session 01 can begin with concepts; establish my OS, shell, and editor before platform-specific setup in Session 02.
4. Give a short session map and begin the first manageable concept or task.

During the session, use a flexible rhythm: explain, let me predict or attempt where useful, give a small implementation step, let me run it, and discuss the result. Pause at meaningful verification boundaries. Adjust depth to my understanding instead of enforcing a fixed number of bullets, lines, or questions.

At the end, recap what we verified, offer one small optional exercise without immediately revealing its solution, recommend a Git checkpoint if appropriate, and provide the [cross-chat handoff](13-cross-chat-handoff.md). I will run Git myself. Mark partial work honestly; do not advance dependent lessons past unresolved blockers.
